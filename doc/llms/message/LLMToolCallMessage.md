# LLMToolCallMessage

Represents a request from the AI model to call a tool.

## Syntax

```matlab
msg = aisdk.llms.message.LLMToolCallMessage(name, arguments, toolCallID)
```

## Description

`aisdk.llms.message.LLMToolCallMessage(name, arguments, toolCallID)` creates a tool call message directly.

These messages are typically generated by the model when it decides to invoke a tool during a conversation.

## Properties

| Property | Type | Description |
|----------|------|-------------|
| `Role` | `string` | Always `"assistant"`. Identifies this as a tool invocation request. |
| `Type` | `string` | Always `"tool-call"`. |
| `Content` | | Inherited from `LLMMessage`. Not used for tool call messages. |
| `Name` | `string` | The name of the tool the model wants to call. |
| `ToolCallID` | `string` | A unique identifier for this tool call, used to match it with its result. |
| `Arguments` | `struct` | The arguments the model is passing to the tool. |

## Examples

```matlab
msg = aisdk.llms.message.LLMToolCallMessage("getWeather", struct("city", "London"), "call_01");
msg.Name       % "getWeather"
msg.Arguments  % struct with field city = "London"
```
