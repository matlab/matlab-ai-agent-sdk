# LLMMessage

Create LLM messages for conversations.

## Syntax

```matlab
msg = aisdk.LLMTextMessage(content)
msg = aisdk.LLMTextMessage(content, Role=role)
msg = aisdk.LLMImageMessage(source)
msg = aisdk.LLMImageMessage(source, Detail=detail)
msg = aisdk.LLMToolCallMessage(name, arguments, ToolCallID=id)
msg = aisdk.LLMToolResultMessage(result, ToolCallID=id, Name=name)
```

## Description

Messages are created using the concrete message classes directly. Each class represents a specific message type in the conversation.

`aisdk.LLMTextMessage(content)` creates a user text message from a string or char.

`aisdk.LLMTextMessage(content, Role=role)` creates a text message with the specified role (`"system"`, `"user"`, `"assistant"`, or `"tool"`).

`aisdk.LLMImageMessage(source)` creates a user image message from a file path, URL, or MATLAB image array.

`aisdk.LLMImageMessage(source, Detail=detail)` sets the image resolution detail level (`"auto"`, `"low"`, `"high"`, or `"original"`).

`aisdk.LLMToolCallMessage(name, arguments, ToolCallID=id)` creates a tool call message. These are typically generated by the model.

`aisdk.LLMToolResultMessage(result, ToolCallID=id, Name=name)` creates a tool result message returned to the model.

## Examples

### Text messages

```matlab
msg = aisdk.LLMTextMessage("Hello!")
msg = aisdk.LLMTextMessage("I am an assistant message!", Role="assistant")
```

### Image from a MATLAB array

```matlab
img = imread("peppers.png");
msg = aisdk.LLMImageMessage(img)
```

### Image from a file path

```matlab
msg = aisdk.LLMImageMessage("photo.jpg")
msg = aisdk.LLMImageMessage("photo.jpg", Detail="low")
```

### Image from a URL

```matlab
msg = aisdk.LLMImageMessage("https://example.com/cat.jpg")
```

### Multi-turn with images

```matlab
msgs = [aisdk.LLMTextMessage("What is in this image?"), ...
        aisdk.LLMImageMessage("peppers.png")];
```

### Tool messages

```matlab
toolCall = aisdk.LLMToolCallMessage("getWeather", ...
    struct("city", "London"), ToolCallID="call_01")

toolResult = aisdk.LLMToolResultMessage("Sunny, 22C", ...
    ToolCallID="call_01", Name="getWeather")
```
