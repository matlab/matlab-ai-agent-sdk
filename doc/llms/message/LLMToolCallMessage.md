# LLMToolCallMessage

Represents a request from the AI model to call a tool.

## Syntax

```matlab
msg = aisdk.LLMToolCallMessage(name)
msg = aisdk.LLMToolCallMessage(name, arguments)
msg = aisdk.LLMToolCallMessage(name, arguments, ToolCallID=id)
```

## Description

`aisdk.LLMToolCallMessage(name, arguments, ToolCallID=id)` creates a tool call message.

These messages are typically generated by the model when it decides to invoke a tool during a conversation.

## Properties

| Property | Type | Default | Description |
|----------|------|---------|-------------|
| `Role` | `string` | `"assistant"` | Always `"assistant"`. |
| `Type` | `string` | `"tool-call"` | Always `"tool-call"`. |
| `Name` | `string` | | The name of the tool the model wants to call. |
| `Arguments` | `struct` | `struct()` | The arguments the model is passing to the tool. |
| `ToolCallID` | `string` or `[]` | `[]` | A unique identifier for this tool call. May be `[]` when the provider does not return one (e.g., Ollama). |

## Examples

```matlab
msg = aisdk.LLMToolCallMessage("getWeather", struct("city", "London"), ToolCallID="call_01");
msg.Name       % "getWeather"
msg.Arguments  % struct with field city = "London"
```
